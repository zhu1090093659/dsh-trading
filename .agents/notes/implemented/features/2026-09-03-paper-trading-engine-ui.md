## 1. 业务诉求与设计定位

交易终端此前已打通了真实实盘报单（`dryRun: false`）与连接器错误阻断机制。为了让交易员无需申请真实 API Key 即可低门槛练习盘感、验证策略，需要引入全功能模拟交易（Paper Trading / Demo）系统。

在主流专业交易所（OKX、Binance、富途牛牛、TradingView）中，模拟交易必须具备：
1. **零混淆与强防错**：交易者在看盘敲单时，必须一眼识别当前是实盘真钱还是虚拟资金；
2. **全局模式双轨**：下单面板与资产账本同频联动，不发生信息割裂；
3. **安全物理隔离**：模拟数据 100% 本地闭环，严禁向券商或交易所发起实盘请求。

---

## 2. 方案 1 落地：三大核心 UI 锚点

### ① 顶部工具栏全局分段切换胶囊 (`QuoteStage.tsx`)
- 位于顶部图表周期（1m/5m/1d）右侧操作区，紧挨「交易工作台」开关；
- 采用 Segmented Capsule 布局：
  - `[ ⚡ 实盘交易 ]`：深色质感；
  - `[ 🧪 模拟交易 (Demo) ]`：激活时呈高亮琥珀黄（Amber）；
- 点击模式持久化于 `localStorage`（`dshtrading:trade:mode`），切换为模拟盘时自动唤起交易面板。

### ② 右侧下单面板联动 (`OrderPanel.tsx`)
- **标题栏标示**：右上角展示琥珀黄 `[🧪 模拟盘 (虚拟资金)]` 标签；
- **资金快捷重置**：右上角配备 `[↺ 重置模拟金]` 按钮，支持一键恢复 100,000 初始虚拟资金；
- **可用额度提示**：展示实时虚拟可用余额；
- **防错下单按钮**：主按钮自适应为 `[🧪 模拟买入 (ETH)]` / `[🧪 模拟卖出 (ETH)]`，外加虚线警告框。

### ③ 底部资产抽屉联动 (`TradeDrawer.tsx`)
- 左侧 Tabs 前标明 `[🧪 模拟盘账本]`；
- 四大页签（当前持仓、活动委托、成交流水、账户余额）直接展示虚拟账户真实计算结果；
- 右侧增加快捷 `[↺ 重置模拟金]` 按钮。

---

## 3. 本地模拟撮合引擎 (`paper-trading-store.ts`)

- **撮合逻辑**：市价单立即以实时 Ticker 最新价成交，限价单按指定价成交；
- **资金核算**：买入扣减可用现金并按加权平均成本更新持仓均价；卖出检查持仓足额，平仓释放现金；
- **行情跳动追踪**：接入 `QuoteStage` 的 Ticker 推送，动态调用 `updatePrices` 实时重估持仓未实现盈亏（`unrealizedPnl`）；
- **数据持久化**：存储于 `localStorage`（`dshtrading:paper:account:v1`），支持跨刷新保存与一键清空重置。
