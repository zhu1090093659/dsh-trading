# Agent Note: 特殊指标滞后语义与容器边缘自适应

Status: implemented

## Problem

用户 2026-10-09 反馈两条，都发生在中栏「特殊指标」视图：

1. **「数据滞后」徽标误报**：10-08 数据（节后首个交易日）在 10-09 上午正常显示时，恐慌指数卡片与板块融资卡片仍挂「数据滞后」。用户口径：T+1 指标在交易日显示 T-1 数据是常态，不算滞后。
2. **容器边缘不适配**：会话侧栏展开/关闭切换时视图不跟随。实测 1600x900 视口下侧栏展开，中栏只剩 503px，板块融资仍按双栏渲染，双轴图被压到 25px；同时卡片右侧越出面板 26px，产生横向滚动条。

## Decision

**滞后判据改为「上游数据日 vs 预期数据日」**（`wire.ts` 新增 `isDataBehind(dataDate, expectedDate)` 与两个快照级包装 `sentimentDataStale` / `sectorsDataStale`）：

- 恐慌指数卡片用 `date < expected_data_date`，板块融资卡片用 `data_date < expected_data_date`；相等即新鲜——T+1 口径下显示上一交易日数据不标滞后，只有数据日真正落在预期交易日之前（长假后迟迟未补、上游断更）才标。
- 桥（node 半 SWR）的 `stale` 信封标记**不再驱动徽标**。该标记语义是「本次响应由过期窗口缓存立即服役」，与「数据本身落后」正交：缓存 60s TTL 一过就置位，数据日却可能已是最新。基差卡片上游无数据日口径，直接撤掉徽标；恒科卡片只认上游自身 `stale` 字段。
- 日期为 ISO `YYYY-MM-DD`，字典序即时间序；任一日期缺失一律不判滞后（宁可不标，不误标）。

**边缘适配改按「容器宽」而非「视口宽」**（`SpecialIndicatorsView.module.css`）：

- `.root` 声明 `container-type: inline-size`，板块双栏/单栏断点由 `@media (max-width: 1100px)` 改为 `@container (max-width: 900px)`。中栏宽随会话侧栏开合变化，视口宽不反映它——旧写法在 1600px 视口下侧栏展开仍留双栏。
- `.card` 补 `box-sizing: border-box`。卡片是「铺满面板内容宽」的块，`width: 100%` 按 content-box 计算时，边框盒会比面板内容宽多出 `12*2 + 1*2 = 26px`，右缘越界并产生横向滚动条。
- 阈值 900px 由内容反推：双轴图宽 = 中栏 − 24(面板 padding) − 26(卡片 padding+边框) − 440(排行表) − 14(栏间距)，中栏 900px 时图区约 396px。

**门禁固化**（`scripts/ui-functional-check.mjs` G 段）：

- G1 改判卡片**外框**（`offsetWidth`）等于面板内容宽。旧断言比较 content-box，而 content-box 布局下的溢出恰好让两者相等——旧断言把 26px 越界判成了全绿。
- 新增 G5「面板横向溢出 ≤ 0」；新增 G6「侧栏展开后按容器宽自适应」：视口锁 1400px（宽于旧阈值），展开侧栏把中栏压到 703px，断言必须堆叠且双轴图 ≥ 200px。该用例在旧实现下 G1/G5/G6 三项全红（已做负向对照）。

## Alternatives considered

- **保留桥 `stale` 徽标、另加数据日徽标**：同一位置两个徽标语义重叠，用户看到的仍是「数据滞后」；桥标记对日频指标本无信息量，放弃。
- **把桥 SWR 标记降级成整卡降透明度**：`.cardRefreshing` 已承担「后台再验证中」的可见反馈，再叠一层没有新增语义，放弃。
- **按窗口宽 + 侧栏状态两个变量手算中栏宽**：要读 shell 折叠状态并持续同步，中栏宽还有其它来源（工具详情列、窗口缩放）；容器查询把这件事交给浏览器布局，零 JS 状态，放弃手算。
- **保留 `@media` 只调阈值**：侧栏展开时视口仍是 1600px，任何视口阈值都对中栏实际宽视而不见，是同一类缺陷，放弃。
- **给卡片不改 box-sizing、改 `width: calc(100% - 26px)`**：把 padding+border 的几何值写死进宽度，改 padding 就失配；`border-box` 是同一意图的标准表达，放弃。

## Consequences

- 「数据滞后」只表达「数据落后于应有交易日」：10-09 显示 10-08 不标；长假后停在节前日期才标。桥缓存服役仍由整卡降透明度（`.cardRefreshing`）与刷新按钮如实反馈，不再劫持滞后徽标。
- 视图宽度分支跟随中栏实际宽：侧栏展开把中栏压到 900px 以下时自动单栏堆叠，双轴图保持可用；实测 4 档视口 × 侧栏开合共 8 组组合横向溢出全部为 0。
- `wire.ts` 新增三个导出纯函数（`isDataBehind` / `sentimentDataStale` / `sectorsDataStale`），包内私有面，无跨包消费者。
- 实测（trading-web 桌面宿主 127.0.0.1:54586，headless Chrome CDP）：侧栏展开 1600x900 下板块页签由「双栏 + 图区 25px」变为「双栏 + 图区 399px、零溢出」；1400px 视口侧栏展开为中栏 703px 单栏堆叠、图区 653px；10-08 数据下滞后徽标全部消失。包内 50 例全绿，`ui:check` 14 项全绿。
