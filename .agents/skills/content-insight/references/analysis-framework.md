# 内容深度分析与知识沉淀框架

本框架源自一次完整的实战验证（B站财经类视频 → 字幕转写 → 事实核查 → 11页分析报告），
后扩展支持微信公众号文章（正文提取 → 核查 → 分析），提炼出可复用的分析流程、
核查方法与输出模板。适用于观点评论类、知识科普类、时事解读类内容；
纯娱乐类内容（歌舞、剧情、vlog）只需走到"结构拆解"即可止步，不必强行套用全部维度。

## 来源适配要点

| 环节 | B站视频（转写稿） | 微信文章（提取稿） |
|------|------------------|-------------------|
| 底稿特性 | 口语流，有同音字误差，无标点段落 | 编辑过的书面文本，结构完整，可能有图表数据 |
| 结构拆解 | 依赖语义切分段落 | 优先利用小标题/加粗/序号等显式结构信号 |
| 核查重点 | 口误、口头数字更易不准 | 注意图表中的数据（纯文本无法核查，需标注"图中数据待核"） |
| 体裁意识 | 脱口秀式即兴推理，逻辑跳跃常见 | 公众号体裁多样：复盘/科普/软文/情绪文，先判体裁再选核查深度 |
| 基本信息节 | UP主/时长/发布链接 | 公众号/作者/发布时间/原文链接 |

## 一、五维分析框架

按顺序对转写文稿执行以下五个维度。每个维度的产出直接对应报告章节。

### 维度1：内容结构拆解
- 目的：还原视频的论证链路，看清"作者想让我相信什么、他是怎么论证的"。
- 方法：
  1. 通读全文，切分出视频的段落骨架（典型的结构如：现象引入 → 原因解读 → 推演预测 → 行动建议）；
  2. 为每个段落标注：核心主张 / 使用论据 / 修辞策略（诉诸权威、诉诸情绪、类比、数据引用）；
  3. 画出主张之间的依赖关系：后续结论建立在哪些前置假设之上。
- 产出物：结构拆解表（段落 | 核心主张 | 论据类型 | 依赖假设）。

### 维度2：观点核实（事实核查）
- 目的：区分"事实骨架"与"观点加工"，这是分析类视频价值判断的根基。
- 必查项清单（按优先级）：
  1. **关键数字**：百分比、金额、涨跌幅——逐个与公开数据源对照；
  2. **时间与事件**：事件发生时间、地点、主体是否准确；
  3. **人物头衔与身份**：职务、任期、任命时间（人名+职务最容易张冠李戴）；
  4. **直接引用**：声称"某某说过/报道说"的原话，尽量找到原始出处对照；
  5. **独家性声称**："五个工作组""内部消息"这类无法公开核实的表述，明确标注"无法核实"并说明原因。
- 核查操作：使用 web-search，每条声称独立搜索，中文+英文各试一次；结果保存为 JSON 备查。
- 结论标注法（三档，报告与知识卡片中必须显式使用）：
  - ✅ **证实**：有权威来源直接支持（注明来源）；
  - ⚠️ **有出入**：方向正确但数字/细节与公开信息不符（写明差异）；
  - ❓ **无法核实**：无公开来源可对照（不等于虚假，但要提示读者）。

### 维度3：逻辑与立场评价
- 目的：评价论证质量，而非评价立场对错。
- 检查点：
  1. 事实骨架是否可靠（承接维度2的核查结果）；
  2. 归因是否过强：单一事件是否被解释为复杂系统的唯一原因；
  3. 推演链条中的假设负载：从"事实A"跳到"结论B"中间隐含了多少未经验证的假设；
  4. 利益相关性：UP主是否在推广产品/服务，是否影响其叙事选材；
  5. 情绪化修辞与事实陈述的比例。
- 表述准则：对事不对人；评价论证质量而非动机揣测；用"该推理依赖……假设"替代"作者在误导"。

### 维度4：背景补充
- 目的：补齐观众理解所需但视频未讲的上下文。
- 方法：围绕视频主题检索 2-4 条背景信息（行业背景、历史沿革、术语解释），
  只补充"理解本视频所必需"的内容，不展开成独立百科。

### 维度5：实践启示与知识沉淀
- 目的：把"看过"变成"可复用的知识与经验"。
- 提炼三类资产：
  1. **分析框架**：视频中可迁移的思考结构（如"从市场反应反推政策意图"）；
  2. **事实清单**：经核实成立的关键事实（可作为后续分析的地基）；
  3. **避坑提示**：视频中暴露的常见认知陷阱（如"不溯源的关键数字"）。
- 产出物：知识卡片（模板见下文第三节）。

## 二、报告结构模板（docx/pdf 深度报告）

生成深度报告时调用 docx skill（或按用户指定格式），正文按以下结构组织：

```
封面：内容标题 + 副标题"内容深度分析报告" + 日期
目录
1. 内容基本信息        —— 标题/UP主或公众号/时长或发布时间/链接/转写或提取方式说明
2. 内容结构拆解        —— 段落骨架 + 论证链路（维度1）
3. 关键观点核实        —— 核查表：声称 | 公开信息 | 核实结论 | 来源（维度2）
4. 逻辑与立场评价      —— 可靠性/归因强度/假设负载/利益相关（维度3）
5. 背景补充            —— 理解所需的上下文（维度4）
6. 综合评价与启示      —— 三句话结论：能否信 / 价值在哪 / 怎么用（维度5）
附录：完整底稿文稿      —— 转写稿（视频）或提取稿（文章）
```

篇幅基准：5-10分钟视频或3000字内文章对应 2000-3000 字正文；核查表至少覆盖 5-8 条关键声称。
写作立场默认客观中立，如用户另有要求（如"站在投资者视角"）按用户要求调整。

## 三、知识卡片模板（轻量沉淀，markdown）

深度报告之外，额外产出一张知识卡片，便于沉淀进个人知识库。保存为
`知识卡片_<主题>.md`：

```markdown
# 知识卡片：<主题关键词>

- **来源**：《<标题>》 @<UP主或公众号>（<BV号或文章链接>）
- **日期**：<分析日期>
- **内容可信度**：高 / 中 / 低（一句话依据）

## 核心论点（素材说了什么）
- <用2-4条概括，保留原作者的推理链>

## 事实核查结论（哪些可信）
- ✅ <证实的事实，注明来源>
- ⚠️ <有出入的地方>
- ❓ <无法核实的地方>

## 可复用的分析经验（能带走什么）
- <从该视频学到的分析框架/视角，用"当遇到X情况时，可以用Y框架"的句式>

## 适用边界与避坑
- <这套论述在什么条件下成立、什么条件下失效>
- <该视频暴露的认知陷阱>
```

## 四、分析立场红线

1. **区分转述与背书**：报告转述观点时用"UP主认为/文中称/据视频称"，核实性内容才用直接陈述。
2. **区分无法核实与虚假**：核查不到 ≠ 造谣，结论标注"无法核实"而非"错误"。
3. **数字必须溯源**：报告中引用的每一个数字，要么来自素材（标注"视频中称"或"文中称"），要么来自公开来源（标注来源）。
4. **投资/医疗等专业建议加免责**：素材若涉及投资、健康等决策建议，报告须明确提示"不构成决策依据"。
5. **不做动机审判**：评价论证与证据，不猜测创作者个人意图。
