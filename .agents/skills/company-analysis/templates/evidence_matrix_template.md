## 信源等级

| 等级 | 说明 |
|---|---|
| S | 财报、监管文件、交易所公告、公司公告、招股书、原始数据 |
| A | 官方统计、公司电话会、权威行业协会、主流财经数据库、头部媒体原始采访 |
| B | 券商研报、行业报告、第三方数据库、媒体深度报道 |
| C | 财经自媒体、新闻聚合、二手摘要、未经完整披露的研报摘录 |
| D | 社媒、论坛、视频博主、传闻 |
| E | 无出处截图、AI 摘要、无法追溯来源的信息 |
