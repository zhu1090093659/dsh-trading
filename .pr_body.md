## Summary

This PR addresses **Issue #19** by providing a complete, agent-native custom indicator authoring, sandbox validation, persistence, and charting workflow:

### 1. Pure Function Sandbox Validator (`packages/indicators/src/validate.ts`)
- **Five-Fold Assertions**:
  1. Structural & param validity (`id` lowercase alphanumeric 2-32, reserved ID protection, `title` 1-32, `pane` 'main'|'sub', 0-8 `params`).
  2. Source code size bound (≤ 16KB).
  3. Sandbox test calculations across 5 distinct kline scenarios (uptrend, downtrend, flat, price gap jump, short 3-bar history) with execution timeouts.
  4. Output shape alignment (`values.length === bars.length`).
  5. Finite value & warm-up assertions (strictly requires `undefined` for warm-up and finite numbers; rejects `NaN`, `Infinity`, or malformed types).

### 2. Agent Tooling (`indicator_author`) & Storage
- `packages/indicators/src/tool.ts`: Implements `createAuthorIndicatorTool`, returning clear structural diagnostic feedback on failure to guide LLM self-reflection and automatic repair.
- `packages/indicators/src/custom.ts` & `custom-fs.ts`: In-memory storage for browsers/tests and JSON file persistence for Node host.

### 3. Knowledge Skill Distribution (`indicator-authoring/SKILL.md`)
- Distributed with package (Iron Rule #2).
- Contains complete contracts, calculation rules, color conventions (China red-up/green-down tokens), and **3 production-grade Futu-aligned golden examples**:
  - **TD9** (Tom DeMark 9-turn sequence, main chart overlay)
  - **SuperTrend** (ATR-based dynamic volatility channel, main chart overlay)
  - **OBV + MA34** (On-Balance Volume + 34-period SMA, sub-chart dual line)

### 4. HTTP Bridge & Client Live Sync (`packages/client-ui-trading`)
- Extends `/dshtrading/api/indicators/custom` with GET and DELETE routes.
- Web client asynchronously fetches and validates custom indicators on load/reload, dynamically registering them into `indicators`.
- Indicators automatically appear in the chart's quick indicator tags strip and can be mounted with 1-click.

### 5. Verification
- `pnpm -r build`: All 19 packages built with zero errors (100%).
- `pnpm -r test`: 251+ tests passed green (100%).
- Added comprehensive unit tests for validator failure cases, TD9/SuperTrend/OBV golden cases, tool execution, and bridge routes.
- Added Agent Note under `.agents/notes/implemented/feature/2026-08-31-author-custom-indicators.md`.

Closes #19
