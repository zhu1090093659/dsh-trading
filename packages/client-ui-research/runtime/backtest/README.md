# 回测模块

第一版覆盖 **A股 / 美股 / 港股的日线**，长线与短线两种口径。做T 单独一期（见下）。

```python
from backtest.gate import plan_backtest
from backtest.run import run
from backtest.strategies import MaCross

plan = plan_backtest(codes=["600519.SH"], start="2022-01-01", end="2025-12-31", style="long")
if not plan:                       # Refusal 的 __bool__ 是 False
    print(plan.reason, plan.remedy)
else:
    print(run(plan, MaCross(20, 60)).summary())
```

## 内置策略（`strategies.py`）

买入持有 · 均线交叉 `MaCross` · RSI 均值回归 `RsiReversion` · RSRS 择时 `Rsrs`。RSRS 按光大证券 2017 年公开研报的公式自写
（最近 n 天最高价对最低价的最小二乘斜率，取它在最近 m 个读数里的标准分，越过 ±阈值换目标权重），没有搬任何仓库的代码；
前 n+m-1 根只算指标（`warmup_bars`），跑完由 `result_notes()` 把方法出处、预热期、第一个读数和平仓记录太少写进口径。
只用于历史回测，不输出当天的读数。

## 闸口（`gate.py`）

跑之前先判**这个回测成不成立**，三问：

1. **要回测什么** — 代码 → 市场 → 引擎与市场规则
2. **需要什么** — 口径（长线 / 短线 / 做T）→ bar 粒度、最少多少根
3. **限制是什么** — 这个市场 + 这个口径下哪些事根本做不了

只输出两种东西：能跑的 `Plan`，或说得清的 `Refusal`。**没有"带一堆警告勉强跑"的第三种** ——
警告没人看，数字人人看。

一个不成立的回测照样能算出夏普和最大回撤，排版整齐、看不出异常。闸口的价值在**拦住**。

现在会拦住的：混市场 · A股做T（T+1 表达不了）· 任何市场做T（没有分钟数据）·
样本不够 · A股要做空 · A股 ETF / 指数 / 可转债（日线取数只覆盖个股）· 认不出的代码 · 区间反了 · 本金非法或买不起一手。

## 市场规则（引擎内置，随结果一起呈现）

| | 做空 | 回转 | 涨跌停 | 最小单位 | 费用 |
|---|---|---|---|---|---|
| **A股** | 不允许 | T+1 | 主板 ±10% / 双创 ±20% / 北交所 ±30% | 100 股整手 | 佣金万2.5(低5元) + 过户费万0.1双边 + 印花税万5卖出 |
| **港股** | 允许 | T+0 | 无 | 按 100 股简化 | 印花税 0.1% 双边 + 征费 |
| **美股** | 允许 | T+0 | 无 | 支持碎股 | 零佣金 |

涨跌停按**前收**判，不是当日收盘 —— 后者是未来函数。A 股另取一份不复权的开盘价和前收，按交易所规则算涨跌停价（不复权前收 ×(1±限幅)，四舍五入到分）：开盘就在涨跌停价视为封板、不成交；没封板但加上滑点会越过涨跌停价的单子也不成交。取不到不复权价时退回复权价上的近似判定，并在数据来源里写明。

## 数据

走本产品自己的取数端点，**不用上游那 25 个 loader**：回测吃的每一根 bar 都带 `raw_ref`，
与看板上的数字同源、可复算。A股 `bs_kline_qfq`（前复权，含 `preclose` 与停牌标记）；
美股 · 港股 `yahoo_kline`。全部零鉴权。

对照基准按市场自动选（`loader.INDEX_BENCHMARKS`，代码带 `INDEX:` 前缀，与标的分开记）：

| 市场 | 基准 | 端点 |
|---|---|---|
| A股 | 沪深300指数 `INDEX:sh000300` | `tx_kline`（腾讯日 K，不复权） |
| 美股 | 标普500 ETF `INDEX:SPY` | `yahoo_kline` |
| 港股 | 盈富基金 `INDEX:02800.HK`（跟踪恒生指数） | `yahoo_kline` |

基准是价格序列，不含分红再投资；港美股用跟踪指数的 ETF 代替指数。取不到时退回**等权买入持有所测标的本身**，
披露里写明，不悄悄当成指数。

## 输出（`cli.py`）

- `metrics`：43 项数值指标（另有对照指数的代码和名称两个文字字段），收益 / 风险 / 交易统计 / 对基准（超额、信息比率、跟踪误差、Beta）/ 补充指标（`report_data.extended_metrics`）。
  没有定义的比率是 `null`，不是 0。
- `tables`：月度收益、年度收益（含基准）、最深 5 段回撤，读自引擎写出的 `equity.csv`。
- `robustness`：夏普重抽样置信区间、分段检验；`sensitivity`：均线、RSI、RSRS 三个内置策略在邻近参数上的网格（RSRS 是回归天数 × 阈值，标准化窗口不动；`sensitivity.py`，有时间预算，不标最优）。
- `cost_compare`：扣费前后对照（`cost_compare.py`）。同一份数据、同一套信号把费用和滑点设为零再跑一遍，给不计成本的总收益 / 年化 / 最大回撤 / 夏普 / 成交笔数，
  以及 `drag`（成本吃掉的收益，小数）；只用来量成本，不是能做到的收益。重跑失败或仍扣了费用时是 `{"error": ...}`，主结果照常。
- `required_disclosures`：价格口径、费率、指标定义等强制披露，由编排层原样附在报告末尾。
- `ui_only.charts`：传 `charts: true` 时附逐日净值 / 回撤 / 基准序列，只给界面画图；编排层交给 Agent 前整块去掉。
- `action: "catalog"` 返回给 Agent 的能力说明（参数表 + 基准、图表、多标的等「不是参数但每次都有」的说明）。

## 运行期守卫（`run.py` 的 `_Guarded`）

闸口是拿到数据**之前**判的，只能按日历估。真实数据与信号到手后还有两件事只有这时才知道，
而它们都会产出一份看着完全正常的报告：

- **实际 bar 数不够**（次新股 / 长期停牌 / 数据缺）→ 中止；单只票不足该口径最低要求 → 报告里点名
- **带预热的策略**（策略声明 `warmup_bars`，如 RSRS）：能持有的根数（实际根数 − 预热）不够该口径最低要求 → 中止并写明还差多少；单只票同样点名
- **策略发出了引擎会静默拒掉的信号**（如 A股做空）→ 中止，因为跑出来的是另一个策略
