# 全球品种交易风控检查清单（global-risk-checklist）

适用范围：全球市场品种——现货贵金属（XAUUSD 等）、能源（WTI/USOIL）、外汇主流货币对、
全球股指（SPX 等）。开仓前逐项核对；任何一项不通过即不入场，并将未通过项写入交易计划的
风险栏。数据来源约定：行情与品种名册以金十连接器（global_quote / global_klines /
global_instruments，GUI 经 tradingGlobalMarketData 路由）返回为准；本清单不构成投资建议。

**依据闸门（先过）**：每条开仓理由必须能指回锚点（工具名 + 参数 + 数值 + 数据时间 / 公告或章节 / facts 条目 / 知识卡 id + updatedAt）。只有 C/D/E 级来源、或写不出锚点的理由，按证据不足处理（insufficient），不得作为入场依据。

## 1. 杠杆与保证金（仅适用于杠杆账户）

- [ ] 现货金/原油/外汇在券商侧通常是保证金交易：先确认自己账户的实际杠杆倍数与保证金要求，按「价格 x 合约规模 x 保证金率」算出单笔占用。
- [ ] 单品种占用保证金不超过账户权益的 20%；全组合合计不超过 50%。
- [ ] 名义杠杆写明倍数；10 倍以上必须给强制减仓触发线。
- [ ] 浮亏按名义价值放大：写明价格反向波动 1% / 3% / 5% 时对应的亏损金额。

## 2. 强平与隔夜利息

- [ ] 用当前保证金率倒算强平价并写进计划；杠杆头寸隔夜是常态风险，不是例外。
- [ ] 外汇与贵金属杠杆头寸有隔夜利息（swap/展期成本）：持仓跨日先确认多空方向的费率，长周期持仓把累计展期成本计入盈亏平衡点。
- [ ] 账户风险度（占用保证金/权益）超过 70% 停止加仓，超过 80% 主动减仓，不等强平。

## 3. 交易时段与跳空

- [ ] 全球品种近似连续交易（周一 06:00 — 周六 05:00，北京时间），但流动性分亚/欧/美三盘：美盘活跃、亚盘早期与两盘交界点差明显放大，市价单按盘口价差折算滑点后再评估。
- [ ] 每日收盘休市段（北京时间 05:00-06:00）前后流动性枯竭：避免临休市挂新仓。
- [ ] 周末与节假日休市是跳空高发窗口：周一开盘跳空穿越止损单是常态，按跳空 2% 压力测试最大亏损；重大地缘/数据事件前（如非农、FOMC、OPEC 会议）评估是否减仓过周末。

## 4. 事件与数据驱动波动

- [ ] 金十财经日历（econ_calendar）核对持仓期内的重大数据发布：非农、CPI、FOMC、GDP 等发布瞬间点差急剧放大且滑点失控，数据行情前不新开市价单。
- [ ] 原油核对 OPEC+ 会议、EIA 库存时点；贵金属核对实际利率与美元指数联动；黄金与美元/实际利率强负相关，不要用单一品种观点对冲另一品种的美元敞口。
- [ ] 相关性 ≠ 同一性：做多黄金同时对冲美元空头，要写明相关性假设与失效条件（相关系数漂移即失效）。

## 5. 美元计价与汇率

- [ ] 全球品种报价以美元计价（client 台账 global → USD）：非美元账户核对折算汇率与换汇成本，台账基准币切换（USD/CNY/HKD）不改变品种本身盈亏。
- [ ] 以 CNY/HKD 思考盈亏时，叠加人民币/港币对美元波动：品种盈利可能被汇率回吐，反之亦然。

## 6. 品种与数据面核对（连接器能力边界）

- [ ] 金十源只有分钟 K 线且单窗口 100 根（本仓最多拼 300 分钟）：GUI 只上 1m/5m/15m，日线及以上显式报错——长周期结构与历史回测需另行取数，不得用分钟数据冒充日线。
- [ ] 闭市返回空 K 线序列是真实语义（≠ 故障）：周末/节假日取数为空不作为「数据源坏了」重试。
- [ ] 现货价 ≠ 期货价：XAUUSD 是现货金，与 COMEX 期金存在基差；USOIL 是 WTI，与布伦特价差独立存在，跨市场套利先核对合约口径。
- [ ] 本市场为纯数据面（无下单/账户工具）：任何真实交易走券商侧人工流程，agent 输出仅作计划与提醒，dry-run 语义。
