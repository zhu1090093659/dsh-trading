## 1. 适用判断与周期边界

当利润主要取决于外生价格、销量/产量和单位成本时，按周期股处理。常见对象包括养殖、航运、金属、能源、化工、存储、面板、造纸、建材和强周期制造。

先写一句周期边界声明：

> 本报告把周期定义为从供给/价格/库存的一个可验证低点，经上行和盈利兑现，到下一次可验证回落；当前周期尚未完成时，只与历史可比上行段比较，不把它伪装成完整周期。

用官方统计、行业协会、交易所数据、公司披露或权威数据库确定边界。不要只用股价高低点反推行业周期。

至少覆盖最近两个完整周期或可比上行段。若其中一轮由疫情、战争、禁运、疫病、自然灾害或监管骤变驱动，把它标成“冲击型超级周期”，单列其可复制部分和不可复制部分。

## 2. 两轮周期证据包

为每轮周期和当前阶段收集同一口径的数据：

| 层级 | 必收字段 |
|---|---|
| 行业 | 周期区间、供给/产能/库存、需求、政策、期货曲线、全年均价、月度或现货峰值 |
| 公司 | 销量/产量、单位重量或单位量、实现价格、完全成本、单位价差、归母利润、CFO、Capex、FCF、净资产 |
| 市场 | 股价低点/高点、市值低点/高点、PB、适用时的 PE/EV/EBITDA、成交与持仓变化 |
| 时间 | 行业价格低点、供给拐点、季度转盈、利润峰值、股价低点和高点的日期 |

使用以下横向表：

| 周期/上行段 | 边界证据 | 驱动类型 | 年均价与短期峰值 | 供给变化 | 公司量/成本/价差 | 归母利润/FCF | 股价/市值/PB | 领先或滞后 |
|---|---|---|---|---|---|---|---|---|
| 历史段 1 |  | 正常/冲击 |  |  |  |  |  |  |
| 历史段 2 |  | 正常/冲击 |  |  |  |  |  |  |
| 当前阶段 |  | 未完成 |  |  |  |  |  |  |

执行四项口径检查：

- 不把周度、月度或现货最高价当作全年平均实现价。
- 不把公司指导成本当作已实现成本；同时列实际成本和目标成本。
- 不把销量增长全部视为盈利增长；检查重量、产品结构和内部销售抵销。
- 不因历史年份口径不齐而静默拼接；明确重述、会计变化和缺失项。

## 3. 单位经济敏感性

先测机械经营弹性，再校准归母利润：

```text
有效计价量 = 名义销量或产量 × 可归属比例 × 单位换算
单位价差 = 实现价格 - 完全成本
机械利润 = 有效计价量 × 单位价差
机械利润变化 = 有效计价量 × Δ单位价差 + 单位价差 × Δ有效计价量
归母利润能力 = 机械利润 - 期间费用 - 财务费用 - 税费
                 - 少数股东损益 - 内部抵销 ± 存货/套保/会计时点调整
```

用至少一轮历史周期验证“机械利润 → 归母利润”的转化率。若转化率波动大，给区间而不是点估计，并解释差异来自哪里。

单位经济表至少包含：

| 场景 | 有效销量/产量 | 单位量 | 实现价格 | 完全成本 | 单位价差 | 机械利润 | 调整项 | 归母利润能力 |
|---|---:|---:|---:|---:|---:|---:|---|---:|
| 当前现实 |  |  |  |  |  |  |  |  |
| 每 1 单位价差敏感性 |  |  |  |  | +1 |  |  |  |
| 正常周期 |  |  |  |  |  |  |  |  |
| 强周期 |  |  |  |  |  |  |  |  |

在表下注明：这是机械敏感性、周期利润能力还是某一年度预测。三者不得混写。

## 4. 一致预期与场景命名

先抓取带日期的机构一致预期，再命名场景。把收入、归母利润、EPS、BVPS 和适用的行业价格假设放入对照。

| 数据日期 | 一致预期年份 | 利润/EPS/BVPS | 对应原场景 | 是否已覆盖 | 校准后名称 | 超出一致预期所需条件 |
|---|---|---|---|---|---|---|
|  |  |  |  | 是/否 |  |  |

遵守以下命名纪律：

- 若原“牛市”利润已接近下一年一致预期，把它改名为弱修复或正常周期上行。
- 只有明显超出一致预期、且需要额外供给收缩或单位价差扩张的场景，才称为强周期。
- 把依赖不可重复供给冲击的场景命名为“冲击型超级周期尾部”，置信度默认低。
- 若一致预期本身缺乏可追溯假设，只把它当市场定价坐标，不当作事实。

非线性周期默认使用：失效/深度亏损、弱修复、正常周期上行、强周期、冲击型超级周期尾部。允许因行业特征合并为四档，但不得把尾部混入基准。

## 5. 股价领先关系

对每轮历史样本记录：

| 周期 | 股价低点 | 行业价格/供给拐点 | 季度转盈 | 利润峰值 | 股价高点 | 低点领先转盈月数 | 高点领先利润峰值月数 |
|---|---|---|---|---|---|---:|---:|
| 历史段 1 |  |  |  |  |  |  |  |
| 历史段 2 |  |  |  |  |  |  |  |

明确转折点定义和样本数。不要把某两轮得到的固定月数写成普遍规律；异常冲击周期应单列。

用领先关系区分两个研究阶段：

- `预期试错候选`：现实仍弱，但供给/库存/政策/价格的边际变化与历史领先关系一致，市场尚未充分定价。
- `右侧确认`：关键经营指标、行业价格和公司盈利按预设条件转强。

两者都只是研究结论。只有用户明确要求交易计划时，才补充标的、触发价、委托价、数量、有效期、失效和买回条件。

## 6. 估值交叉与双重上市

使用阶段匹配的估值锚：

1. 用可持续单位价差得到周期利润能力。
2. 对峰值或强周期利润使用保守、阶段匹配的倍数；禁止“峰值利润 × 高景气高倍数”。
3. 用历史峰值/中枢市值、PB、当前与未来 BVPS、EV/EBITDA 交叉验证。
4. 若目标价高于历史市值或 PB 映射，解释增量来自规模、成本、净资产积累还是资本结构变化。
5. 若不同锚冲突，扩大区间、下调置信度并解释冲突，不挑最高结果。
6. 从当前股价或市值反推市场隐含的可持续单位价差、利润、持续期和分红，标明反推依赖的估值方法；据此判断市场已交易到弱修复、正常上行还是强周期。

A/H、港美或其他双重上市先估统一权益价值，再分别处理：

| 项目 | 统一经济价值 | A/主上市地 | H/ADR/第二上市地 |
|---|---:|---:|---:|
| 总权益价值 |  |  |  |
| 每股换算 |  |  |  |
| 结构性折溢价 | 不适用 | 流动性/资金结构 | 流动性/税费/汇率/持有人/可转换性 |
| 市场参考价值 |  |  |  |

不要先分别拍两个目标价，再倒推折价理由。

## 7. 关键前提纠错传播

用户挑战关键前提时，先独立复核被挑战命题、原始来源、历史样本、一致预期和最强反证。

若修正成立，按以下顺序传播：

1. 结论摘要与当前周期位置。
2. 证据矩阵和反方证据。
3. 周期边界、历史横向表和股价领先关系。
4. 单位经济、利润敏感性和一致预期坐标。
5. 场景名称、估值区间与 A/H 折溢价。
6. 评分卡的相关分数与置信度。
7. 风险、验证/失效条件和动作层。
8. 一句话结论、图表说明、来源与口径。

不要用“补充说明”保留互相矛盾的旧结论。若修正不成立，也要在证据矩阵写清反证。

## 8. 完成门禁

交付前逐项确认：

- [ ] 已定义周期边界并覆盖两个完整周期或可比上行段。
- [ ] 已分开正常周期与冲击型超级周期。
- [ ] 已分开全年均价与短期峰值。
- [ ] 单位经济已用历史数据校准到归母利润。
- [ ] 已说明一致预期落在哪个场景，场景名称未夸大。
- [ ] 已区分周期利润能力与单年预测。
- [ ] 已测量而非臆测股价领先关系。
- [ ] 未使用峰值利润乘高景气高倍数。
- [ ] 双重上市先统一经济价值，再解释结构性折溢价。
- [ ] 用户纠正若成立，已传播到整份报告而非只追加备注。
