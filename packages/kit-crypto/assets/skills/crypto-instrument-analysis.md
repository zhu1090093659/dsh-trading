# 加密标的定性分析框架（crypto-instrument-analysis）

对单个加密标的做定性分析时按本框架五步推进。原则：**每一步的数据必须来自工具调用并标注时间**，禁止凭记忆报数；结论必须附反方情景。

## 第零步：定位

- 标的是什么（币种、赛道、现货/永续）；用 `crypto_get_ticker` 确认符号存在且报价新鲜（timestamp 距今超过 1 分钟的行情要说明）。
- symbol 一律市场规范词汇（如 `BTCUSDT`），不要用交易所方言。

## 第一步：趋势结构（多周期一致法）

1. `crypto_get_klines` 取 1d（看方向）→ 4h（看结构）→ 1h（看时机）；根数默认 300 足够。
2. `crypto_get_indicators` 计算 MA(5/10/20) 与 MACD(12/26/9)：
   - MA 排列：短期 > 中期 > 长期 且全部上行 = 多头排列（反之空头）；交织 = 震荡，降置信度。
   - MACD：DIF/DEA 位置（零轴上下）与柱体缩放方向；柱体背离价格新高/新低是结构减弱信号。
3. **置信度规则**：三个周期方向一致才允许用"趋势"一词；仅 1d 一致只说"日线偏多/偏空"。

## 第二步：量价配合

- K 线 volume 与价格方向：上涨放量、回调缩量为健康结构；价升量缩（背离）标注为脆弱信号。
- 尾部 3-5 根出现异常放大（> 近 30 根均量 2 倍以上）必须单独说明并检查是否有消息面（见第五步）。
- **陷阱**：低流动性标的（小市值、新上线）的量价信号整体失真——先确认标的主流性，再决定量价结论的权重。

## 第三步：波动率

- `crypto_get_indicators` 的 BOLL(20,2)：当前价在带内的位置（上轨附近=强势或超买，需结合趋势方向解读）；带宽收窄 = 变盘临近，方向不定。
- 波动率放大的时段（重大宏观数据、周末薄流动性）下调一切结论的操作置信度。

## 第四步：资金面

- `crypto_get_funding_rate`（永续）：当前费率与近期序列。
- **判读**：费率极端正值（年化显著高于常态）= 多头拥挤，回调风险；极端负值反之。费率是**反向拥挤指标**，不是方向指标。
- 费率对持仓的意义：顺费率方向持仓有成本收益，逆费率方向持续付费要计入持有成本。

## 第五步：新闻面（占位）

- `crypto_get_news` 工具交付后（WS2b，issue #4）启用本步：取时间窗内新闻，**每条必须带来源与发布时间**，区分事实（公告、上币、监管动作）与观点（媒体评论）。
- 工具未交付前，明确写"新闻面未覆盖"而不是编造。

## 输出格式

1. **定性结论**（一句话：方向 + 结构状态 + 关键条件）
2. **依据清单**（每个数据点标注：工具名 + 参数 + 数值 + 时间）
3. **反方情景**（什么数据出现会推翻本结论——必须具体到指标与阈值）
4. **置信度**（高/中/低 + 原因；单周期、新闻面未覆盖、低流动性至少占其一即不得标高）

## 禁止事项

- 禁止不带数据引用的结论（"我觉得"、"大概率"无依据支撑）。
- 禁止把指标当预测：MA/MACD 是确认工具，滞后于价格。
- 禁止跳过反方情景——定性分析的价值一半在能被证伪。
- 本框架是方法论，不构成投资建议；涉及交易一律遵守铁律 #3（dry-run 起步 + 显式开关 + 审批）。
