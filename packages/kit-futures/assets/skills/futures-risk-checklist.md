# 期货交易风控检查清单（futures-risk-checklist）

开仓前逐项核对；任何一项不通过即不入场，并将未通过项写入交易计划的风险栏。
数据来源约定：行情与合约参数以同花顺连接器（tradingFuturesMarketData）返回为准，
保证金率/合约乘数/最小变动价位可用品种目录核对；本清单不构成投资建议。

## 1. 保证金与杠杆

- [ ] 按当前保证金率（品种目录 margin_rate，非交易所最低标准即可，期货公司实收通常更高）计算单手占用保证金：价格 x 合约乘数 x 保证金率。
- [ ] 单品种占用保证金不超过账户权益的 20%；全组合合计不超过 50%。
- [ ] 名义杠杆 = 名义价值 / 占用保证金，明确写出倍数；10 倍以上必须给强制减仓触发线。
- [ ] 浮亏按名义价值放大：写明价格反向波动 1% / 3% / 5% 时对应的亏损金额。

## 2. 强平与追保

- [ ] 用当前保证金率倒算强平价：多头强平价 ≈ 开仓价 x (1 - 1/杠杆 + 追保缓冲)，空头镜像；写进计划。
- [ ] 账户风险度（占用保证金/权益）超过 70% 停止加仓，超过 80% 主动减仓，不等强平。
- [ ] 夜盘与节假日前提高缓冲：隔夜持仓风险度上限比盘中收紧一档。

## 3. 合约到期与移仓换月

- [ ] 确认所交易合约代码的到期月份（如 CU2601 = 2026 年 1 月），距最后交易日不足一个月的合约原则上不开新仓。
- [ ] 个人客户不能进入交割月：交割月前最后一个交易日前必须平仓或移仓（各品种规则不同，逐品种核对）。
- [ ] 主力合约切换期（主力移仓至次月）注意流动性迁移：老主力持仓减半前不新增老主力仓位。
- [ ] 持仓成本含移仓损耗：跨期价差（近月-远月）对移仓方向不利时，计入持仓成本再评估盈亏比。

## 4. 交易时段与隔夜跳空

- [ ] 该品种是否有夜盘（品种目录 has_night_session）与夜盘收市时间；无夜盘品种隔夜风险显著更高，仓位相应下调。
- [ ] 日盘 09:00-10:15 / 10:30-11:30 / 13:30-15:00，夜盘 21:00 起（收市时间分品种 23:00/01:00/02:30）：夜盘末段流动性差，避免临收市加仓。
- [ ] 隔夜跳空是常态：止损单不保证成交价格（跳空穿越），按跳空 2% 压力测试最大亏损。

## 5. 涨跌停与流动性

- [ ] 该品种涨跌停板幅度（交易所有基础比例并随市场状态调整）：连续停板时可能无法平仓，评估极端情形下的连续亏损敞口。
- [ ] 主力合约以外月份流动性折价：非主力合约按盘口价差与挂单深度折算滑点后再评估。
- [ ] 单笔市价单不超过盘口可见量的 1/3，大单拆分执行。

## 6. 方向与对冲

- [ ] 明确单边投机还是对冲；对冲头寸写明被对冲资产与相关性假设（相关品 != 同一品，基差风险单独评估）。
- [ ] 跨期/跨品种套利写明价差进出场阈值与历史分位，不用单边涨跌观点替代价差逻辑。
- [ ] 同品种双向持仓（锁仓）不降低保证金与风险，只延迟决策——禁止用锁仓回避止损纪律。

## 7. 品种与数据面核对（连接器能力边界）

- [ ] 行情数据当前仅日K与当日分时（同花顺期货源）：分钟级回测与历史分时策略评估需另行取数，不得用当日分时冒充历史分钟数据。
- [ ] 无实盘交易面（dry-run 语义）：任何真实下单走账户侧人工流程，agent 输出仅作计划与提醒。
- [ ] 保证金率、手续费以期货公司实际通知为准，品种目录值为参考快照。
